# Задание 3. Паспорт наборов данных

## UCI SMS Spam Collection

| Пункт | Значение |
|---|---|
| 1. Источник | UCI Machine Learning Repository, авторы T. A. Almeida, J. M. Gómez Hidalgo |
| 2. Ссылка | https://archive.ics.uci.edu/dataset/228/sms+spam+collection |
| 3. Лицензия | Creative Commons Attribution 4.0 (CC BY 4.0) |
| 4. Дата загрузки | 05.11.2026 |
| 5. Язык | Английский |
| 6. Объём | 5574 сообщения (проверено скриптом, совпадает с описанием источника) |
| 7. Классы | ham — 4827 (86,60%), spam — 747 (13,40%) |
| 8. Известные ограничения | Только английский язык; spam ≠ мошенничество в строгом смысле (много обычной рекламы); сообщения собраны около 2012 года, современных схем в них мало; после очистки есть дубликаты |

**Структура исходного файла:** `data/raw/SMSSpamCollection`, без заголовка, разделитель — табуляция.
Столбцы: метка (`ham` / `spam`), текст. Кодировка определяется в `detect_encoding`.

**Результат загрузки:** `data/processed/sms_raw.csv`. Столбцы: `id` (int), `text` (str),
`label` (int: 0 — ham, 1 — spam). Пропусков нет: число строк совпадает с исходным файлом.

## Собственный набор `data/raw/custom_ru_kk.csv`

| Пункт | Значение |
|---|---|
| 1. Источник | Искусственные сообщения, написаны для проекта |
| 2. Ссылка | Файл в репозитории |
| 3. Лицензия | Используется только в проекте |
| 4. Дата создания | 05.11.2026 |
| 5. Язык | Русский, казахский |
| 6. Объём | 150 сообщений: 100 на русском, 50 на казахском |
| 7. Классы | fraud — 75 (50 ru, 25 kk), safe — 75 (50 ru, 25 kk) |
| 8. Известные ограничения | Только для тестирования многоязычности; маленький объём; написан тем же автором, что и словарь правил, поэтому результаты могут быть завышены |

**Автор разметки:** столбец `annotator`. Сейчас там указан черновик от Claude Code.
**Перед сдачей** студент должен проверить тексты и метки и указать себя как проверяющего.

Реальных номеров телефонов, карт и персональных данных нет: номера вида `+7 700 000 00 00`,
а ссылки только на зарезервированных доменах `.example`, `.test`, а также сокращения вида
`bit.ly/...-test`, которые в проекте не открываются.

**Многоязычность.** В открытых наборах из ТЗ казахскоязычных SMS нет. Поддержка русского и
казахского языков не заявляется: обучающие данные только английские, и в интерфейсе ML-оценка
для этих языков отмечена как ненадёжная.
